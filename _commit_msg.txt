Bind the pinned document into every identity, and release v2.1.18

Completes the release. The bundle fingerprint -- one digest over the document
bytes, every extraction path, every expected fragment and the extractor version
-- now travels with the pipeline fingerprint, the normalization recipe, the run
intent and the capture summary. A capture taken under one reading of the
vendor's API cannot verify under another.

The recipe is where this matters most and where it is least obvious. A recipe
*is* the set of rules normalization ran by, and two of those rules -- how
rate_value is read, and where time to expiry is floored -- now come out of a
document. Rebuilding under a different document is rebuilding under different
rules, so `normalized-chain` moves to 2.1.18 along with the run and intent
schemas that gained the documentation block.

Also here:

* `endpoint_drift` checks the five first-session endpoints against the pinned
  bytes for both subscription tier and CSV response fields. All five agree. Two
  details that would otherwise produce false conflicts: `/v3` is the base path
  of the document's own `servers` entry rather than an assumption, and the
  contract list is templated as `/option/list/contracts/{request_type}`.
  `TIER_NOT_DOCUMENTED` is a separate finding from `TIER_CONFLICT`, because a
  silent document has not agreed with us.

* The dry run gains a `vendor_documentation` section: source URL, digest, byte
  length, bundle fingerprint, settlement rule, resolved settlement date, rate
  units, time floor, the remaining unknowns by name, and any drift.

* The stale claims are removed rather than merely contradicted elsewhere. The
  "v3 URLs return 404" and "the production registry is empty" statements are
  gone from VALIDATION.md and the vendor documentation module.
  `test_no_module_still_claims_the_documentation_is_unobtainable` keeps them
  gone. The OD-11 *universe* registry really is still empty and those passages
  are untouched.

* 26 new regressions in tests/unit/test_openapi_evidence.py. None makes a
  network request, and one proves it by making every socket construction raise.
